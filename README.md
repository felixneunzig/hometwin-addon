# hometwin für Home Assistant

Quelle für die App hometwin in Home Assistant: ein digitaler Zwilling der
Wohnung mit berechnetem Licht, Editor in der Seitenleiste und Dashboard-Card.

Hier liegt nur die Beschreibung der App. Die fertigen Container liegen privat
in der GitHub Container Registry unter `ghcr.io/felixneunzig/hometwin-addon-<arch>`
und brauchen in Home Assistant einen Zugang unter „Registries“.

Einrichten in Home Assistant: Einstellungen, Apps, App-Store, oben rechts
„Repositories“, diese Adresse eintragen:

    https://github.com/felixneunzig/hometwin-addon
